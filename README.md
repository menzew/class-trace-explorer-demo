# ClassTrace Explorer Demo

This repository hosts complete interactive reports generated by
[ClassTrace Explorer](https://github.com/menzew/class-trace-explorer).

- [Example gallery](https://menzew.github.io/class-trace-explorer-demo/)
- [HelloWorld](https://menzew.github.io/class-trace-explorer-demo/examples/reports/helloworld.html)
- [SwingSet3](https://menzew.github.io/class-trace-explorer-demo/examples/reports/swingset.html)
- [Apache NetBeans](https://menzew.github.io/class-trace-explorer-demo/examples/reports/netbeans.html)

The reports are self-contained HTML files and execute entirely in the browser.
They contain class names, graph relationships, source metadata, and class-file
footprint measurements from their example traces.

The ClassTrace Explorer source repository is private while its initial public
release is under review.
